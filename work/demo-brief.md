# HTML 界面演示范围

用户已要求先制作模拟数据 HTML 原型，用于电脑评审；本轮不建设真实前后端，不代表批准原生 App 的全部实现。

- 单文件 HTML，无外部依赖，可双击打开；布局呈现手机 App，桌面配流程说明。
- 错题本、拍试卷、练一练三入口；包括框选示例试卷、分类保存、题目详情、原题组卷、A4 预览及重做记录。
- 示例内容为六年级数学，也提供小学旧题；所有模拟识别和遮盖明确标注。
- 优先采用系统字体、暖白和青绿色，大操作区域、可读题目；支持键盘操作和较窄窗口。
- 模拟状态可保存在当前浏览器；支持一键恢复示例。打印调用浏览器打印，真实扫描、OCR、AI、签名均不接入。
- 逐步制作：页面与示例数据 → 可交互流程 → 浏览器实际走查与布局检查 → 修复并交付 HTML。
- 正式构建方式已按用户补充更新为推送 GitHub，在 macOS CI 构建后下载 IPA，由用户自行侧载；实际仓库及 workflow 在正式开发时核对。

核验重点：连续选题不会重复保存、空筛选有反馈、题数不足明确显示、答案默认隐藏、取消不提交、重做结果不重复提交、打印仅含练习卷、刷新可恢复示例状态。

## 用户要求的第二版原型

- 分类改为知识点多选；错因支持选择、自填及历史复用，编辑和保存共用组件。
- 手动组卷支持科目、年级、知识点、错因和加入日期的组合筛选；同一维度多选按任一匹配，不同维度同时满足。隐藏已选题不丢失，数量单独提示。
- 同时打印学生卷及家长页，强制新页；双面打印模式下，学生卷为奇数页时补一页，以确保家长页从新一张纸开始。需与打印机的单双面设置一致。
- 主流程改为拍已完成卷、模拟识别、批改结果核对、统一确认入库；不明确的结果不能直接保存。保留手动入口，并防止同一次结果重复入库。
- 保存并迁移旧版模拟数据；发布独立的 shiti-demo-v2.html，同时更新原 shiti-demo.html。
- 仅制作用户明确要求的模拟原型，不接模型、真实拍摄或真实批改，不创建 GitHub 构建。

## 用户确认的 V2.2 调整（2026-10-21）

- 明确分开出卷打印和做完后拍照两阶段：生成即保存，初始状态待完成，打印窗口不代表已完成；以后从我的练习卷找回。
- 练一练顶部常驻“生成练习卷 / 我的练习卷”，卷列表独立于选题长列表，支持搜索和状态筛选。
- 卷名可显式修改，默认“我的数学巩固练习18”等；跨科目共用独立连续出卷序号，仅新建成功递增，改名、重印、拍照和删除不影响序号。
- 错题可单个或批量移入最近删除，练习卷可逐份移入；最近删除中可恢复，本轮不提供永久清理或自动到期销毁。
- 删除错题不破坏练习卷快照；删除练习卷不删除题库题目和已确认结果，只暂停该卷未确认草稿入口。恢复后重现其原状态。

## 用户确认的 V2.3 删除规则（2026-10-22）

- 只允许待完成练习卷，以及最近确认结果为暂未做且无待核对批改的错题删除；尚未重做不属于暂未做。
- 列表、详情、批量勾选、打开确认框与实际提交共用判断，批量任一项不合格则整批不执行。
- 已确认卷不能通过重印重新获得删除资格；旧版回收站仍能恢复原状态，恢复后按新规则判断。
- 输出 shiti-demo-v2.3.html 并同步已有 HTML 文件。检查确认取消、状态变化、历史保留和回收站兼容。

## 用户确认的 V2.4 补充（2026-10-22）

- 新演示直接具备两道可删除暂未做错题、一题暂未做但待核对的对照；两份待完成卷和待核对、已记录卷各一份。旧数据可追加样例，不覆盖用户改动、不重复补充。
- 我的练习卷提供批量管理、禁选说明、全选当前可删除、清空、隐藏已选提示和确认前重新校验；操作栏放在列表上方并保持可访问。
- 使用清新蓝色主色、浅蓝背景与白色卡片，保持现有流程，作为未来原生 iOS 15.5 及以上版本的视觉参考。
- 输出 shiti-demo-v2.4.html，旧文件名同步。真实 App 不预装模拟样例和演示引导。
