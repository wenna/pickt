# 拾题 · V2 交互演示

用电脑浏览器打开 `shiti-demo-v2.html`。原来的 `shiti-demo.html` 也已更新，可以按 Ctrl+Shift+R 刷新。页面顶部可看到“界面演示 V2”。单文件不需要联网、安装依赖或运行服务器。

建议按“拍试卷 → 多知识点和错因分类 → 保存 → 我自己选 → 筛选 → 组卷 → 打印全部 → 拍完成卷 → 核对批改结果 → 确认入库”的顺序体验。

## 这次新增的操作

- 保存错题：每题点“修改分类”，可选多个知识点和错因，也可自填。确认保存的内容会变成后续可选项；也可以明确统一设置全部题目。
- 手动选题：上方“筛选题目”可按科目、年级、知识点、错因、加入时间及掌握状态组合筛选。切换条件保留已选题，筛选外已选数量有单独提示。
- 打印：支持只打印当前部分，或者一次打印学生卷及家长页。整套输出强制分页；启用双面且学生卷为奇数页时自动补白。请在打印机中选择相同的单双面设置，保存 PDF 也沿用同样的分页。
- 练习记录：点击“拍完成卷，记录结果”，模拟拍照后查看逐题批改。待确认题目处理完才能统一保存。可修改识别答案和判断，也可标记暂未做。需要时可用手动记录入口。

## 数据和演示范围

所有题目、手写示例及批改结果均为虚构内容。拍摄和批改使用预设结果，不访问相机、不读取照片、不接入 OCR 或大模型。真实批改准确率及打印效果不能由本演示保证。

模拟记录尝试保存在当前浏览器。旧版本的单知识点、错因及记录会在读取到同一存储时迁移；不同浏览器、本地文件路径或隐私模式不一定共享数据。可从右侧或家长设置中恢复新的 8 道初始示例，体验更多科目和加入日期的筛选。

当前已通过模拟流程与打印内容结构检查；实际浏览器视觉、鼠标框选和打印分页效果尚未完成走查。完整合并取舍与建议体验顺序见 `新版功能合并说明.md`。
