# 拾题 · V2.4 交互演示

用电脑浏览器打开 `shiti-demo-v2.4.html`。此前的 HTML 链接也已更新，可以按 Ctrl+Shift+R 刷新。页面顶部可看到“界面演示 V2.4”。单文件不需要联网、安装依赖或运行服务器。

先体验“拍试卷 → 分类保存 → 练一练顶部‘生成练习卷’→ 选题和组卷 → 改名 → 打印 → 稍后再做，回到我的练习卷”。生成时已经自动保存，退出再回来也能找到。纸上做完后，再从“练一练 → 我的练习卷 → 对应卷 → 做完后拍完成卷核对”进入识别和记录，不需要出卷后马上拍照。

## 这次新增的操作

- 我的练习卷：从练一练顶部直接切换，不再放在选题长列表末尾。支持名称搜索、待完成/待核对/已记录筛选，以及逐份改名；只有待完成卷可单个或批量删除。
- 批量删练习卷：进入“练一练 → 我的练习卷 → 管理练习卷”，勾选待完成卷，或点“全选当前可删除”，再点列表上方的“删除所选练习卷”。待核对及已记录卷禁选；切换筛选保留已选并提示隐藏数量，可清空选择。操作栏滚动时仍可访问。
- 配色：改为清新蓝色、浅蓝背景和白色卡片，作为后续原生 iOS App 的视觉参考；当前文件仍只是电脑上查看的 HTML Demo。
- 卷名与编号：点击预览页标题或列表“修改名称”。默认名称如“我的数学巩固练习18”，跨科目共用独立出卷序号；只有新建一份才递增，其他操作不占号。
- 删除错题：仅最近已确认结果为“暂未做”、且没有待核对批改的错题可删除。详情支持单题操作，错题本顶部“管理错题”支持批量操作；不可删除的题禁选，并显示原因。尚未重做不属于暂未做，刚收录的题不能删除。历史卷中的题目快照保留。
- 删除练习卷：列表和预览中仅“待完成”卷可删除；打印过但未开始批改仍可删除。“待核对”“已记录”卷显示禁用原因，重新打印不会解锁删除。不删除题库和既有记录。旧版已在最近删除中的卷仍可恢复原状态，恢复后按新规则判断删除资格。
- 确认与提交：打开确认框和提交时均重新校验；批量中任何一题状态不合格，则全部不删除并提示数量与原因。取消确认不会保留旧删除请求。
- 最近删除：错题本、我的练习卷和家长设置均有入口，支持恢复原内容。本演示不自动永久清理。

- 保存错题：每题点“修改分类”，可选多个知识点和错因，也可自填。确认保存的内容会变成后续可选项；也可以明确统一设置全部题目。
- 手动选题：上方“筛选题目”可按科目、年级、知识点、错因、加入时间及掌握状态组合筛选。切换条件保留已选题，筛选外已选数量有单独提示。
- 打印：支持只打印当前部分，或者一次打印学生卷及家长页。整套输出强制分页；启用双面且学生卷为奇数页时自动补白。请在打印机中选择相同的单双面设置，保存 PDF 也沿用同样的分页。
- 练习记录：点击“拍完成卷，记录结果”，模拟拍照后查看逐题批改。待确认题目处理完才能统一保存。可修改识别答案和判断，也可标记暂未做。需要时可用手动记录入口。
- 自动默认分类：保存前预填科目、年级和知识点，显示建议来源；允许多选和修改，保存即采用当前分类。错因仍按实际情况填写。这里的识别建议是预设示例。
- 错题本回看：卡片显示最近结果，按“最近结果 / 核对进度”筛选再练练、暂未做或待核对；进入详情可查看“练习与未作答记录”，并进入对应批改对照。暂未做不计错，也不增加有效练习次数。
- 继续核对：未确认批改自动暂存。退出或刷新后，从错题本“待核对”进入详情，或打开该练习卷，可继续核对；它不会提前覆盖原有结果。

## 建议重点检查删除流程

初次打开已包含 11 道题、4 份练习卷。若沿用了旧浏览器数据，先点击顶部“补充体验数据”，不用清空原有内容。补充只执行一次；删过的示例请到最近删除恢复，重复点击不会自动复活。正式 App 不预装这些模拟资料。

快速入口：

- 点击“看暂未做错题”→“管理错题”：两道可勾选；另有一题因待核对而禁选。
- 点击“看待完成练习卷”→“管理练习卷”→“全选当前可删除”：可一次删除两份示例卷。
- 切换到“全部”：待核对及已记录示例卷应禁选并显示原因。
- 删除后进入“最近删除”，检查题目和卷均可恢复。

其他流程：

1. 在错题本进入“管理错题”：做对、再练练、尚未重做的题应禁选并显示原因。
2. 选两题生成练习卷，确认“待完成”时可删除；取消后打印，仍应保持待完成。
3. 纸上完成后模拟拍完成卷：存在待核对草稿时，该卷及相关错题都不可删除。
4. 在真实核对流程中把确实未作答的示例题标为“暂未做”，统一确认入库。该卷应为已记录且不可删除；那道暂未做的错题应可删除。不要为了删除而故意改成暂未做。
5. 删除该题后，从最近删除恢复，检查分类和历史记录仍在。若有其他卷正在核对这题，它仍应被禁止删除。

## 数据和演示范围

所有题目、手写示例及批改结果均为虚构内容。拍摄和批改使用预设结果，不访问相机、不读取照片、不接入 OCR 或大模型。真实批改准确率及打印效果不能由本演示保证。

模拟记录尝试保存在当前浏览器。旧版本的单知识点、错因及记录会在读取到同一存储时迁移；不同浏览器、本地文件路径或隐私模式不一定共享数据。可从右侧或家长设置中恢复 11 道题和 4 份练习卷的初始示例（会清空本演示中的改动），体验更多科目和加入日期的筛选。
