# 错题积累 App：首版设计方案

建立日期：2026-10-20；最近更新：2026-10-22。状态：提议稿，供评审；原生 App 尚未开发、编译或真机验证。

2026-10-22 删除规则调整：练习卷仅“待完成”可删除；错题仅最近一次已确认结果为“暂未做”、且没有待核对批改时可删除。V2.4 Demo 已同步该限制：单题、批量、列表和详情入口共用规则，打开确认框及提交时均重新校验；不合格的整批操作不执行。

用户增补已合入 HTML 原型 V2.4：自动分类建议、多知识点及可复用自填错因、组合选题、整套输出、拍卷核对和错题结果查询；练习卷与生成入口在顶部分区，支持延后拍卷、改名及独立出卷序号，符合当前状态条件的错题与练习卷支持删除和恢复。以下页面、数据与验收章节均已同步。自动分类、拍摄和批改目前均为模拟。

## 1. 要解决什么问题

让孩子把纸质试卷中的错题快速积累起来，按知识点找到需要练习的题，重新组卷打印，做完后记录是否掌握。

已知条件：孩子目前六年级，包含部分小学旧题；数学优先，结构上兼顾之后的初中数学和理科；系统最低 iOS 15.5；家庭自用；使用免费账号侧载并定期刷新；暂不购买大模型 API。

设计假设：第一版服务一个孩子，不设登录；主要在纸上答题；家长处理答案核对、备份及可选 AI 设置。教材版本不预设，允许自行选择和维护。若仍需多科目，沿用同一流程。

附件作为功能素材逐项评估，其中“完美排版”“高精度还原”等描述不作为已经验证的技术能力。

## 2. 三种路线与建议

| 路线 | 能力与代价 | 适合程度 |
| --- | --- | --- |
| 纯本地 | 拍卷、框选、分类、原题组卷、打印均离线；不提供开放式 AI 出题 | 最简单可靠，但缺少新题建议 |
| 本地核心 + 可选免费模型 | 核心完全离线；家长自行配置免费模型，生成知识点建议和相似题草稿 | 推荐，满足零模型采购预算，也保留扩展空间 |
| 云端识别和题库平台 | 更容易接入重模型、同步和共享，但需要服务器、维护及可能的费用 | 家庭首版暂不采用 |

推荐第二条路线，但先交付完整本地闭环，再接入可选 AI。免费模型不可用时，拍题、查题、组卷、打印仍可用。

## 4. 给孩子使用的界面

底部三个入口：**错题本、拍试卷、练一练**。原卷管理和设置放在错题本顶部，减少主界面选项。

### 4.0 视觉方向与适配

采用清新蓝色、浅蓝背景和白色卡片，面向小学高年级至初中孩子，保持简洁清楚，不使用幼儿化的卡通和装饰。V2.4 HTML Demo 先以配色调整体现该方向，现有页面结构和操作流程保留。

| 用途 | 默认颜色 |
| --- | --- |
| 主按钮、选中状态、主要操作 | `#246BD4` |
| 主按钮按下或强调 | `#194D9C` |
| 页面背景 | `#F5F9FF` |
| 浅蓝辅助区域 | `#EAF3FF` |
| 正文 | `#213952` |
| 次要文字 | `#61768C` |

警示保留橙色，删除等操作保留提示色，并配合文字解释，不只靠颜色区分状态。试卷打印继续使用白纸、清晰题干及独立答案页。正式原生 App 统一管理这些颜色，可在开发时整体调整，无需改变数据和业务规则；无需首版再增加主题切换设置。

iOS 15.5 及以上以原生页面实现同一视觉方向，不直接照搬 Windows 演示的手机外框和桌面左右说明栏。正式界面适配安全区域、系统字体放大和不同屏幕，主要点击区域至少 44 点；小屏和大字模式下，批量操作栏不能遮挡列表、底部导航或确认弹窗。这些仍需真机验收，HTML 演示不代表已完成 iOS 适配。

### 4.1 拍试卷

1. 点击“拍试卷”，选择相机扫描或相册。
2. 检查整页是否清楚，必要时旋转或调整边缘。
3. 在整页上拖动矩形框选一道题；框选时可放大，边框有明显控制点。
4. 点击“加入错题本”，自动给出科目、年级和知识点建议；年级优先采用卷面信息，识别不到时明确标为沿用孩子/本次设置。每题可有多个知识点。
5. 分类页显示“自动建议 · 待确认”，可以修改、删除或新增标签；点击“采用当前分类，保存”表示确认当前建议。也可以标为待分类后先收题。错因按孩子实际情况选择或自填，不从照片直接断定。

一题可以有多个图片片段，按顺序组成完整题目，用于题干与图分离、跨页或题干与选项分离的情况。自动分题可作为之后的辅助，不能阻止手动操作。

相机权限拒绝时说明如何开启，并保留相册导入入口；扫描硬件不支持时回退到普通拍照和手动裁剪。取消操作不保存半成品，已保存的其他题目不受影响。

### 4.2 错题本

卡片显示题图缩略图、多个知识点、掌握情况、最近一次确认的结果和日期；有尚未确认的批改时另外显示“批改待核对”。默认显示“待巩固”，并提供“最近结果 / 核对进度”的筛选：全部、再练练、暂未做、做对了、待核对。选择结果筛选时切换为全部掌握情况，避免遗漏已掌握但此次未作答的题；科目筛选仍保留。

详情页先显示最近一次结果；有暂存批改时显示所属练习卷和“继续核对这份批改”入口。下方为清晰题图、分类及来源、原卷、答案与解析，以及“练习与未作答记录”。每次记录显示日期、结果、来源及所属练习卷，可进入当次批改对照。答案默认收起；未录入答案时明确显示“尚未添加答案”。

错因默认选项为“计算出错、题意没看清、方法不会、知识点不熟、其他”，允许多选和自填；已保存的自填项进入历史选项，不因题目被修改而消失。展示避免消极评价。

### 4.2.1 三类状态与错题本中的表现

| 维度 | 状态 | 展示与计算规则 |
| --- | --- | --- |
| 掌握情况 | 待巩固、已掌握 | 独立显示在卡片；做错会回到待巩固，一次做对不自动标记掌握；暂未做不改变掌握情况 |
| 单次结果 | 做对了 | 卡片展示最近结果；详情保留当次记录，计入有效练习次数 |
| 单次结果 | 再练练 | 卡片展示，支持单独筛选；详情保留错题结果，计入有效练习次数并进入复习候选 |
| 单次结果 | 暂未做 | 卡片和详情均可查看，支持单独筛选；保留当次未作答记录，不计错、不计入有效练习次数、不提高掌握程度；仅最近确认结果为此状态、且无待核对批改的题可删除 |
| 单次结果 | 尚未重做 | 从未确认过练习或未作答结果时显示；不能与一次练习中的“暂未做”混为一类，新收录且尚未重做的题不可删除 |
| 批改进度 | 待核对 | 批改草稿另存，卡片另加提示；可继续核对，不覆盖原有最近确认结果、不提前计入统计；存在此状态时不可删除，即使上次结果为暂未做 |
| 批改进度 | 已确认 | 生成正式结果记录，去掉对应草稿提示；可查看原识别答案、人工修正和最终结果 |

“练习与未作答记录”同时显示有效练习次数和暂未做次数。重复查看或重复确认同一次批改不新增记录；同卷重新拍摄并确认是一次新的练习。若同一道题还有其他卷的未确认草稿，其待核对提示仍保留。

### 4.3 练一练

“练一练”顶部分为**生成练习卷 / 我的练习卷**两个常驻分区，滚动选题列表时仍可直接切换，不把已保存卷列表放在长选题列表最下方。生成分区内保留“帮我选题 / 我自己选”，完成后进入预览，调整名称、题序、答题空间，再打印或保存 PDF。

生成成功即自动保存练习卷，初始状态为“待完成”。打印后用户可以退出 App，到纸上做题；以后从“练一练 → 我的练习卷”搜索或筛选找到对应卷子，再拍已完成卷核对。生成和回收核对是两个时间上独立的阶段，不要求生成后立刻拍照。“我的练习卷”提供全部、待完成、待核对、已记录筛选；可打开和改名，仅待完成卷允许删除，待核对和已记录卷不可删除。列表标题旁提供“管理练习卷”，进入后可勾选待完成卷，并提供“全选当前可删除”“清空选择”“删除所选练习卷”。已选数量和删除按钮位于列表上方，长列表滚动时仍可访问；不用拖到末尾寻找批量删除入口。

纸上练习完成后，打开对应练习卷，拍摄或导入已完成卷，生成逐题批改结果；识别出的答案可修正，判题不明确的题先由家长核对，再统一确认加入记录。支持“做对了 / 还需练习 / 暂未做”；暂未做不计错，答对不自动等同掌握。逐题手动记录保留为备用入口。HTML 原型只模拟这些步骤，不提供真实识别或判题。

手动选题增加科目、年级、知识点、错因、加入日期和掌握状态的组合筛选；知识点及错因在同一维度内任一匹配，不同维度同时满足。切换筛选不清除已选题，筛选外仍被选择的数量需明确显示。

### 4.3.1 保存分类与选题筛选的具体交互

保存多题时可逐题打开分类编辑器，每题独立多选知识点、错因和新增内容；详情页复用同一编辑器。“统一设置全部题”必须明确说明会替换本次所有题目的分类。新增内容在保存题目后进入历史，取消编辑不提交修改。

手动选题的筛选窗口提供科目、年级、知识点、错因、加入日期和是否包含已掌握题；日期可选今天、最近 7 天、最近 30 天或自定义起止日期，边界日期包含在内，开始晚于结束时阻止应用。应用只改变候选列表，取消不改变原条件；清除筛选和清空已选是两个独立动作。题数不足显示实际数量，不补入无关题。

### 4.3.2 拍完成卷、核对、回到错题本

1. 从原练习卷点击“拍完成卷，记录结果”，拍摄完整页或从相册导入，按练习卷与题号关联作答。
2. 生成逐题识别与判定草稿，保留识别答案、判定建议及不确定原因；不确定、缺题、字迹不清与无法判定不能直接等同做错。
3. 草稿自动暂存；从错题本“待核对”、错题详情或该练习卷均可继续核对。刷新或退出后仍保留，尚未改变练习统计。
4. 对照参考答案，允许修改识别文字和最终结果。修改识别文字后必须重新确认结果；全部题都有明确结果后统一入库。
5. 将做对、再练练、暂未做都写入该题的结果记录，并保存批改来源与修改痕迹；只有做对和再练练计入有效练习次数。未作答不是错答，也不自动更新复习掌握程度。
6. 确认后更新错题卡片的最近结果和详情历史，清除本次未确认草稿；同一次批改用唯一记录标识防止重复入库。原练习卷中保留整份批改记录及多次练习结果。

识别失败、参考答案缺失或题型无法判定时显示待核对，允许手动完成；人工记录是统一入库流程的备用入口。免费识别/模型不可用时不自动切换收费服务、不伪造判定。自动批改需要单独验证手写、题号、等价答案、单位、步骤及部分正确情况；不能把文字识别当作已经判对题目。

### 4.3.3 练习卷生命周期和名称

| 阶段 | 卷状态与可用入口 |
| --- | --- |
| 生成并保存 | 待完成；可改名、预览、调整题序、打印或保存 PDF，也可返回我的练习卷；允许删除 |
| 打印、纸上作答 | 仍为待完成；打开打印面板不能证明成功打印，更不能标记已经做完，不自动产生对错记录；状态未改变时仍按待完成规则允许删除 |
| 以后返回、拍已完成卷 | 从我的练习卷打开对应卷进入拍照；识别草稿生成后显示待核对，不再允许删除 |
| 核对并确认入库 | 已记录；可查看本次及历史批改结果，错题本同步结果；不允许删除 |
| 同卷重新练习 | 重新打印不新建卷、不占用序号，也不把已记录卷改回待完成；新尝试未确认时显示待核对，保留以前结果；两种状态均不可删除 |

卷名可在预览页点击标题修改，也可从我的练习卷列表直接修改。默认格式为“我的数学巩固练习18”“我的语文巩固练习19”，不加额外空格或前导零；跨科目共用一个连续出卷序号，混合科目使用“我的综合巩固练习20”。

出卷序号使用独立持久化计数器，仅成功新建一份练习卷时递增。收题、改名、打印、保存 PDF、拍照、批改和删除/恢复均不增加或回收序号；选题为空、取消生成不能占号。修改名称不改变卷子内部标识、原序号或已有记录。旧卷迁移优先保留已有序号，必要时从原默认名或卷标识恢复，不能从共享业务计数器继续随意跳号。

### 4.4 家长设置

家长入口容纳备份恢复、知识点维护及可选 AI 配置；AI 开关默认关闭。若启用家长 PIN，应提供提示和本地恢复策略；PIN 不是资料加密承诺。

主要操作按钮至少 44pt，使用系统字体缩放；图标配文字，状态同时用文字表达。删除进入可恢复的“最近删除”，避免误触直接清空。首版原型提供移入和恢复，不自动到期清空、不提供永久清理；未来若增加永久清理，须另行设计确认和关联资源处理。

### 4.5 错题、练习卷删除和恢复

删除资格以状态为前提，单题、批量、列表、详情及未来其他入口共用同一套规则。符合条件才可移入最近删除，不提供绕过状态限制的快捷入口。

#### 4.5.1 哪些状态允许删除

| 对象 | 允许删除 | 不允许删除 |
| --- | --- | --- |
| 练习卷 | 当前为待完成，即没有任何已确认练习结果，也没有待核对草稿；生成后仅打印过、不曾生成批改草稿的卷仍属于此类 | 待核对、已记录；已经记录过结果的卷，重新打印或再次作答也不能恢复删除资格 |
| 错题 | 最近一次已确认结果为暂未做，且没有来自未删除练习卷的待核对批改 | 尚未重做、最近结果为做对了或再练练、存在待核对批改；不能因为历史上某次暂未做就允许删除 |

“暂未做”使用确认入库后的单次结果，不凭拍照时识别到空白自动认定。“尚未重做”与“暂未做”明确分开，因此新收录但未经过一次确认记录的错题不可删除；不为取得删除资格而提供强制改成暂未做或将已记录卷改回待完成的操作。历史上有其他结果，但最近确认结果为暂未做的错题可按上表判断；原有历史仍须保留。

#### 4.5.2 入口、提示和提交校验

错题详情在符合条件时提供单题删除；错题本顶部“管理错题”只允许勾选符合条件的题，其他题的勾选禁用并显示原因。我的练习卷列表及预览页仅待完成卷提供可用删除入口；列表另有“管理练习卷”供批量勾选。待核对、已记录卷禁选并说明原因。“全选当前可删除”只增加当前搜索及状态筛选结果中符合条件的卷，不勾选不可删除项；切换条件保留已选内容，并显示筛选外已选数量。完成管理或清空选择后取消勾选。

两类删除都先提示影响范围。打开确认框和实际提交时再次按最新数据校验，不能只依赖按钮是否可见；确认期间状态发生变化则拒绝执行。错题或练习卷的批量提交若包含任意不符合条件的项，整批不执行，显示不可删除数量及原因，要求刷新后重新选择，不能静默删掉部分题。

确认且校验通过后，仅移入最近删除；错题本、我的练习卷和家长设置保留最近删除入口，分错题/练习卷恢复。恢复不是一次新的删除，不按删除资格拦截；恢复后再删除仍须重新满足当前条件。

| 操作 | 影响与保留 |
| --- | --- |
| 删除符合暂未做条件的错题 | 从活跃题库、搜索、筛选和新组卷中移除，并取消该题尚未生成卷的选中状态；保存原图、分类及所有历史结果，历史练习卷的快照不变 |
| 删除待完成练习卷 | 从我的练习卷中移除；不删除题库中的错题，不修改其他卷或题目的既有结果；新规则不允许删除带待核对草稿或已确认结果的卷 |
| 恢复错题 | 恢复原标识、分类与所有结果，可重新参与筛选；不自动恢复此前已取消的选题勾选 |
| 恢复练习卷 | 恢复原名、序号及题目快照；按新规则删除的卷恢复后仍为待完成，不占用新序号 |
| 兼容旧版已删除内容 | 对旧规则下已进入最近删除、可能带历史结果或草稿的内容保留恢复能力和原数据；恢复后按真实状态展示，不伪装成待完成或暂未做，也不允许再次绕过新规则删除 |

首版不自动永久清理，避免侧载更新和孩子误触导致无法恢复。若未来允许真正释放空间，只能删除已无任何题目、卷快照、批改记录引用的资源，不能因移入最近删除就直接擦除共用图片。目录中的历史知识点和错因不随单题删除消失。

### 4.5.3 仅用于 Demo 的体验数据

V2.4 新开空演示时预置 11 道题和 4 份练习卷，其中新增 3 道数学错题：两道最近确认结果为暂未做、无待核对批改，可以删除；另一道最近确认结果同为暂未做，但存在待核对草稿，用于展示禁选原因。暂未做记录关联一份真实存在于模拟数据中的已记录卷，不能靠给题目随意贴标签取得删除资格。

4 份示例卷包括两份待完成、一份待核对、一份已记录。两份待完成用于体验批量删除和恢复；另外两份展示禁选。例题与例卷均明确标为体验示例，保存示例记录不代表发生了真实识别。

浏览器存在旧数据时不覆盖、不自动混入：在错题本和我的练习卷顶部提供“补充体验数据”，只补充一次，保留原有名称、分类及历史，沿用现有出卷序号继续分配。删除示例后可在最近删除中恢复；再次点击补充不复活已删除内容。正式 App 的普通题库和练习卷首开为空，不注入这些模拟资料或体验入口。

## 5. 知识点和复习设计

数据结构允许科目 → 学段/年级 → 知识点。先给可编辑的小学数学通用标签：分数、百分数、比和比例、圆、面积与体积、方程、应用题、统计等。它们不是特定教材的完整目录；按实际教材逐步补充，允许一题对应多个知识点。

不让孩子每道题都填完整表单：拍卷时只确定科目，年级有默认值，知识点可以稍后补。每题支持多个知识点，错因可选择、自填并在保存后加入历史选项；批量统一设置必须明确表示将替换本次题目的原分类。AI 可建议知识点，但不能未经确认直接覆盖人工分类。

### 5.1 自动分类建议与人工修改

保存时自动建议属于首版需求，不要求孩子逐题从零填写。优先从卷面标题、已确认科目、OCR 题干和本地知识点目录生成建议；小学常见题可用本地关键词/规则辅助匹配，覆盖能力需用实际题目验证。科目、年级、多个知识点分别保存建议和来源，不能只给一个不透明的“自动分类”结论。

年级能从卷面识别时标记“来自卷面”；缺失时沿用孩子年级或本次选择并标明来源，不能把默认设置冒充识别结果。知识点无法可靠匹配时保留“待分类”或“建议补充”，允许先保存；低可靠建议不强行写成已确认事实。可选免费模型只能补充建议，网络/额度异常不阻止收题。

界面预选建议，用户点击“采用当前分类，保存”才成为正式分类；允许删改任意建议、一次保留多个知识点。手动修改后标记“已手动调整”，后台再次识别不得自动覆盖，需由用户主动重新采用。错因需要孩子或家长根据实际作答选择、自填，单凭题目照片不能确定孩子为什么做错。

HTML Demo 用预设内容模拟建议及来源，不声称已经实现真实分类模型。初始示例题中的人工标签与本次拍题的自动建议也应区分。

### 5.2 复习计算

首版复习规则可理解、可修改：新增或再次做错的题建议次日复习；首次重做正确后建议 3 天后，再次正确建议 7 天后；连续三次有效练习正确可建议标记掌握。以设备本地日期计算；暂未做和待核对不作为对错，也不增加有效练习次数或推进连续答对。它们保留在待练/待核对入口中，不被当作已完成练习。该规则是产品默认设置，不声称是经过验证的个性化学习算法。

## 6. 三种“出卷”要分清

### 6.1 原题重练：首版必做

输入为科目、知识点、题数和是否含已掌握题。推荐排序为：到期未掌握 → 最近仍做错 → 更久未练。优先覆盖所选知识点，再按排序补足题数；同卷不重复同一道题。

题数不足时明确提示实际可用数量，让用户减少题数或放宽条件，不悄悄加入无关知识点。允许手动换题、改题序。自动选题结果显示“为什么选这些题”，例如“百分数中仍需巩固的题”。

这一步是从已有错题生成一张新的练习卷，无需大模型，也不会自动产生新题干。

### 6.2 规则变式：后续的有限离线能力

对经过定义的题型模板，如分数运算、百分数计算、一元一次方程，可改变受约束的参数并用程序计算答案。必须先把原题确认映射到模板；不能对任意照片只改数字就当成正确新题。模板必须验证分母非零、答案范围、单位和条件一致等约束。

### 6.3 AI 相似题：可选扩展

家长确认原题的题干文字、知识点、学段及答案后，向免费文本模型请求少量相似题和参考解答。首轮只尝试文字与基础计算题，不默认支持复杂几何作图和完整理科图形。

模型输出存为“待审核草稿”，与原题分开；题干、答案、解析及来源关联都可修改。结构检查及可计算答案校验只是筛查，不能证明开放题正确。经家长确认后才能进入孩子的正式练习卷。

超时、限流或输出不完整时保存已有草稿并允许手动重试；不自动切换到收费模型，也不自动反复请求。没有可用的免费服务时，隐藏生成入口或显示暂不可用，原题组卷仍然可用。

## 7. 为什么自动去笔迹要单独评估

扫描、透视校正、灰度和提高对比度，与区分“印刷题干”和“手写答案”是不同问题。黑色手写覆盖黑色题干时，简单滤镜无法可靠恢复被遮挡的内容。

首版保存三层资料：导入原图、裁剪与增强参数、可撤销的遮盖标记。所有处理都可回到原图；不能把白色涂抹描述为智能还原。遮盖适合空白答题区内的答案，不适合与题干、图形相交的笔迹。题目受损时提供重新裁剪、补拍空白题或人工补录文字的路径。

后续若评估自动去笔迹，应使用经允许的真实样本，分别看铅笔、蓝黑笔、红色批改、几何图和重叠笔迹的效果。模型可能是图像分割或修复模型，并不一定是大语言模型；开源模型也不等于零成本的托管 API。

## 8. 打印和备份必须做好

### 8.1 单独输出与整套输出

打印默认 A4 纵向、约 12mm 页边距，单栏排版；每题包含顺序号、题图与可选知识点，答题留白可选少/中/多。题图保持比例，按原裁剪尺寸及用户预览调整，不把一行短题无条件拉满整页。记录有效清晰度，缩放过度时提示检查打印效果，不把低分辨率图片称为高清。

普通题整体移到下一页，过长题先提示用户；可按用户确认的片段分段换页，不在文字或图形中间盲目切断。学生卷默认不带答案；已确认的答案可另导出家长参考页，缺失答案不自动编造。新增“打印全部”，同时输出学生卷和家长页并强制分页；双面打印且学生卷为奇数页时补一页留白，确保家长页从新一张 A4 纸开始。打印机设置须与单双面选项一致。AI 草稿未审核不能排入正式卷。

预览可切换学生卷和家长页，保留“只打印当前部分”，并增加独立“打印全部 / 存为 PDF”。整套输出前显示学生页数、家长页数、补白页数和总页数；顺序固定为学生卷、按需补白、家长参考页。家长页与学生卷不仅不能混在同一页面，启用双面时也不得落在同一张纸的正反面。打印和保存 PDF 共用同一分页结构，真实打印需分别验证单面与双面设置。

通过系统打印面板支持兼容的 AirPrint 打印机；其他打印机可先保存 PDF，再用电脑或厂商软件打印。不承诺所有品牌都能直接连接。[Apple 打印接口](https://developer.apple.com/documentation/uikit/uiprintinteractioncontroller)

### 8.2 完整资料备份

“打印 PDF”与“资料备份”是两件事。备份包必须包含：结构化题目数据、原卷及题图、自动分类来源、分类及错因目录、含暂未做的结果记录、未确认批改草稿、练习卷及批改快照，带格式版本和文件校验信息；API 密钥不进入备份。恢复前检查完整性，首版采用明确的整库恢复流程，并先备份当前库，防止误覆盖。

练习卷保存当时的题目快照，修改或删除题库中的题目不改变历史练习卷。备份包含最近删除标记与待恢复内容，恢复备份后仍能看到对应分类。当前不提供永久清除；未来如增加该功能，只能清理没有被其他原卷、题目或练习快照引用的资源。

## 9. iOS 15.5 技术方案

| 部分 | 建议实现 | 边界 |
| --- | --- | --- |
| 界面 | SwiftUI，必要处封装 UIKit | 核心流程只用 iOS 15.5 可用接口 |
| 拍卷 | VisionKit 的 VNDocumentCameraViewController | 运行时检查 isSupported，并提供相册或手动拍照回退 |
| 选题和编辑 | UIKit 图片画布 + 归一化矩形坐标 | 正确处理图片方向、缩放、旋转、多片段和遮盖 |
| 文本识别 | Vision 的 VNRecognizeTextRequest | 本地辅助搜索；中文语言设置按运行时支持列表选择；不承诺数学结构识别 |
| 图像增强 | Core Image | 分辨率受控，后台处理，支持撤销 |
| 保存 | Core Data 保存元数据，Application Support 保存图片 | 大图不塞进单条数据库字段；原子写入和失败回滚 |
| PDF | UIGraphicsPDFRenderer | 预览、分页、留白、答案页 |
| 打印和分享 | UIPrintInteractionController、系统分享面板 | 输出标准 PDF，打印连接另行真机验证 |
| 可选模型 | URLSession + 可替换服务适配层 | 家长输入服务地址、模型标识、个人密钥；HTTPS；密钥存 Keychain |

不将 SwiftData、新系统的文档理解或实时扫描接口作为核心依赖。OCR 完成后更新搜索内容，但失败不影响题图保存。Apple 的扫描接口返回逐页图片；本地识别语言与文档处理能力可参考 [VisionKit](https://developer.apple.com/documentation/visionkit/vndocumentcameraviewcontroller) 和 [WWDC21 文档识别介绍](https://developer.apple.com/videos/play/wwdc2021/10041/)。

数据实体划分为：原卷、原卷页、错题、题目片段、知识点、练习记录、练习卷、练习卷题目快照、AI 草稿。错题保存来源页、年级、知识点、可编辑 OCR、手工答案与解析；练习记录单独存储，不只保存一个可被覆盖的“对/错”字段。

### 9.1 新增字段与关系

- 题目分类：多个知识点、多个错因、自动建议原值、来源（卷面/默认设置/本地规则/可选模型）、确认状态、人工修改标记；同科目和年级单独记录来源。
- 分类目录：内置与历史自填知识点、错因，保存时去重，题目删除或修改不直接清除可复用目录。
- 题目掌握情况：独立字段保存待巩固/已掌握；最近结果从已确认事件派生，不能用一个状态字段同时代表掌握与本次对错。
- 结果事件：题目标识、所属练习卷、批改标识、日期、做对/再练/暂未做、是否计入有效练习、识别作答、人工修正、来源；每次事件保留，不覆盖旧结果。
- 批改草稿：练习卷关联、逐题识别内容、建议、待确认原因、人工核对进度、创建和修改时间。与正式结果分开持久化；确认后原子写入结果事件并清理对应草稿。
- 批改记录：一份练习卷可以有多次尝试，以唯一尝试标识保证重复确认幂等。暂未做同样保留关联，不能只保存在整份试卷中而在错题详情丢失。
- 练习卷标识、出卷序号和可编辑名称分别存储；使用独立的下一出卷序号，与收题/批改业务标识计数分离。卷状态根据是否有未确认草稿及已确认尝试计算，不能由打印面板打开事件推断完成。
- 错题与练习卷分别保存软删除时间；删除资格从最新确认结果、已确认尝试和待核对草稿实时计算，不使用可手工改写的“可删除”标记。界面及数据写入层共用条件，并在提交时一致性校验。活跃查询排除已删除项，历史快照和已确认结果查询保留关联，最近删除单独查询；移入/恢复不重建原标识、不修改出卷序号。

旧数据迁移保留单知识点/错因并转换为列表；能够从已有整卷批改记录恢复的暂未做事件应回填且去重，缺失原始信息不得编造。查询最近结果时按确认事件的时间排序，不因数据迁移把旧记录误当成最新。

按页顺序处理大图并生成小缩略图，限制并行图像任务；应用中断后保留已完成的题目。大文件写完且确认成功后才提交数据库引用，避免出现有题目但没有图片的记录。首版无自建服务器、无强制账户、无广告及行为追踪。

## 13. 交付顺序与验收标准

第一阶段交付本地闭环：扫描/导入 → 框选多题 → 保存分类 → 原题组卷 → A4 PDF/打印 → 重做记录 → 备份恢复。第二阶段再评估模板新题及可选免费 AI。自动去笔迹、Word 和联网题库各自单独验证，不阻塞首版。

用户已要求先制作使用模拟数据的 HTML 界面原型，用于电脑上评审操作流程；该原型不接真实前后端。正式版构建采用用户指定的 GitHub CI 途径。原生开发前再根据原型反馈确定最终规格与任务计划；本文件不代表已经具备可安装 IPA。

首版必须实际通过以下验收：

1. iOS 15.5 真机完成拍照、至少两页导入和连续框选保存；新系统另做一次核心流程检查。
2. 分数、几何图、选择题等样本保存与打印后没有因 OCR 替换而失真；缩放后框选位置正确。
3. 多片段题顺序正确，原图可恢复，遮盖可撤销，应用重启后资料完整。
4. 按知识点筛选组卷，题数不足有提示，同卷不重复，已掌握题默认不进入推荐。
5. A4 PDF 预览与实际纸张核对：题干不被截断、图形不变形、普通题不跨页、答案不泄漏；超长题走显式处理流程。
6. 一台兼容 AirPrint 的打印机完成试打；不兼容打印机至少验证导出 PDF 的替代路径。
7. 记录正确/错误后复习日期符合规则，查看和编辑历史记录不会重复计算练习次数。
8. 断网仍能拍题、分类、搜索、组卷和导出；OCR 失败不会丢题。
9. 导出完整备份到 App 外部，在空数据环境恢复，核对题图、知识点、练习记录和历史试卷；损坏备份拒绝覆盖。
10. 使用实际侧载工具刷新或覆盖更新后验证资料；卸载后的恢复依靠外部备份另行实测。
11. 可选 AI 启用后单独验证价格、网络、限流、草稿审核及敏感信息处理；未审核内容不能混入正式卷。
12. 保存错题自动预填科目、年级和多个知识点建议，来源可见；识别不到年级时显示默认来源，不可靠知识点可待分类。手动修改不会被后续自动结果覆盖。
13. 多知识点、历史错因、自填错因均可保存和复用；逐题编辑与统一设置不会误覆盖其他题，取消不提交。
14. 手动选题组合筛选的同项任一/跨项同时规则、日期边界、空结果、隐藏已选提示及取消筛选行为符合规格。
15. 整套 PDF 和打印的学生卷不含答案；家长页强制另页，双面时遇奇数学生页补白，单面和双面均做实际纸张核对。
16. 拍完成卷产生的待核对草稿可退出、重开并从错题本继续；未确认内容不能提前更改成绩、掌握情况或有效练习次数。
17. 确认做对、再练练和暂未做后，错题卡片、最近结果筛选、详情历史及整卷批改记录一致；暂未做可见但不计错、不增加有效练习次数。
18. 修改识别答案后必须重新确认判断；重复确认同一批改不重复计数，同卷新一次尝试保留为独立记录。
19. 旧版分类、历史错因和可恢复的未作答事件迁移后保留、不重复、不打乱最新结果顺序；恢复备份后未确认草稿入口仍可访问。
20. 我的练习卷可从“练一练”顶部直接进入，不依赖滚动到选题末尾；搜索名称和状态筛选不混入选题控件，长列表滚动时分区入口仍可见。
21. 生成后退出、重新打开仍能找到待完成卷；打印及保存 PDF 不改变完成状态；做完后才从对应卷拍照确认，记录与原卷正确关联。
22. 卷名在列表和预览中均可修改；跨科目默认序号连续，收题、改名、重印、拍照及删除恢复不占号、不回收旧号，空选题不占号，重启后序号保留。
23. 仅最近确认结果为暂未做、且无待核对批改的错题允许单个或批量删除；尚未重做、做对、再练练、待核对均应被拦截。符合条件的删除可取消、可恢复，历史卷快照和原有结果保留，恢复不产生重复题目。
24. 我的练习卷提供明显的管理入口，待完成卷可单个或批量删除；待核对、已记录及已记录后重新打印的卷均不可删除。删除不影响题库，恢复保留原名和序号，不占新号、不改变练习次数。
25. 错题和练习卷的批量选择均禁用不可删除项；提交时状态变更或混入不合格题则整批不执行，并明确原因。详情、列表和数据写入层不得出现删除条件不一致。
26. 旧版已删除内容仍能恢复原状态和资料；最近结果取最新已确认记录而非任意历史记录，不能把空白识别、尚未重做或默认掌握状态误当成暂未做来开放删除。

27. 我的练习卷批量管理支持全选当前可删除、清空选择和筛选外已选数量提示；长列表不要求拖到末尾才能删除；取消确认不删除，提交前状态变化时整批拦截。
28. 原生界面沿用清新蓝色主题，在 iOS 15.5 和较新系统上检查文字放大、安全区域及小屏布局；确认页面可读、操作栏不遮挡内容，打印输出不受主题配色影响。
