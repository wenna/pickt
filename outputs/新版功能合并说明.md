## 建议试走

1. 拍试卷，选两道题，点击下一步。
2. 在第一题上点击“修改分类”，选择两个知识点，自填一个错因并保存；第二题可以使用不同的知识点。
3. 保存错题，点击“用这些题练一练”。
4. 打开“筛选题目”，按年级、知识点、错因和日期组合筛选，观察筛选外已选题的提示；取消和应用筛选的行为不同。
5. 生成练习卷后可以直接改名，点击“打印全部 / 存为 PDF”，查看学生卷与家长页页数及双面补白说明；之后可以退出，先到纸上做题。
6. 以后从“练一练”顶部“我的练习卷”找到对应卷，再点击“做完后，拍完成卷核对”，模拟拍摄。演示时可以直接继续体验，但实际流程不要求生成后立刻拍照。
7. 检查预设的批改结果，核对最后一道“待确认”题，选择做对、再练或暂未做。
8. 统一确认后，回到错题详情查看练习足迹，再打开同一练习记录验证没有重复计数。

## 数据与实现边界

- 页面顶部显示“界面演示 V2.4”。独立新版文件为 `shiti-demo-v2.4.html`，此前的 HTML 链接也同步更新。
- 旧版的单知识点和错因会在读取到旧浏览器存储时转为数组，保留原有记录。不同浏览器或不同本地文件路径不一定共享存储；继续使用原链接更容易延续旧数据。
- 初始示例共有 11 道题与 4 份卷，含英语和科学题、暂未做错题及三种状态的练习卷，加入日期也有不同跨度，方便观察筛选效果。保留旧数据时不会自动把新示例混入旧库；可点击“补充体验数据”保留原数据体验新增样例，或明确恢复初始演示。
- 本轮仍只有模拟前端。拍摄、图片识别、答案匹配和自动批改均使用预设内容，不读取照片、不调用真实模型、不产生 API 调用。
- 正式自动批改需要再验证手写识别、题号对应、等价答案、单位、过程分及模糊答案；不能由本演示推断实际批改准确率或免费服务可用性。
- 程序检查覆盖多选分类、历史错因、组合筛选、保留选题、输出分段/补白、待确认阻止提交、人工修正、重复确认及旧数据迁移。现有 41 项专项检查覆盖删除状态、最新结果、批量原子性、确认期间状态变化、旧回收站恢复、样例追加、卷号连续及批量管理。浏览器已实际验证蓝色界面、可选与禁选、两份卷批量删除与恢复；真实 iOS、打印驱动及纸张效果仍需单独验收。
- 正式 iOS 构建继续沿用 GitHub 编译、下载 IPA、自行侧载的方式；本轮未配置或触发构建。
