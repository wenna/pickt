# 原生 App 首轮试用

这是按 Demo V2.4 实现的原生首轮版本。普通库首开为空，不含演示孩子资料。

1. 拍试卷：扫描或导入照片，先在图上单指画框；已有框内部拖动可移动，拖八个圆点可调整大小，框外拖动可重画，双指缩放与平移。“重置选框”返回整页，整页内部也可重新画框。遮盖编辑器始终单指重画遮盖区域。每道题可以收录多个片段，手动遮盖笔迹；原图保留。下一步多选知识点、错因，补参考答案并保存。连续选下一题。
2. 练一练：筛选后手选题或按数量推荐，生成卷。顶部随时进入我的练习卷，不需要滚动到底部。
3. 打开练习卷可改名、创建不同留白排版、输出学生卷 / 家长页 / 全部。双面全部输出在需要时补白，家长页另起纸张。打印后仍待完成。
4. 纸上做完，打开对应卷，选择页脚排版版本，拍完成卷。逐题框选作答区使用系统 OCR；数值或单选答案只给比较建议，必须人工确认做对 / 再练 / 暂未做。每题点击保存后草稿持久保留，全部核对后才能入库。
5. 错题本可查最近结果、待核对和历史记录；错题和卷的管理入口支持按已确认规则整批软删除，在最近删除恢复。
6. 家长设置可导出完整图片备份包到文件 App，恢复前校验并在 App 内保存原资料安全备份。侧载刷新请覆盖安装，避免卸载丢数据。

## 首轮实现边界

- 真正的本地文字 OCR，不是模拟结果；年级默认六年级，科目默认数学，知识点依关键词给建议，均可修改。未做复杂公式语义理解或整卷自动对齐，拍完成卷需要逐题框选核对。
- 分类逐题保存；当前没有批量统一编辑分类、题序拖动、出卷模板和图库资产自动清理。新排版仅调整留白。没有接入大模型、云同步和付费服务。
- 备份为 `.picktbackup` 文件包，文件 App 的跨服务传输兼容性需设备验收。恢复前安全备份保留在 App 内，不自动清理；可从家长设置的“恢复前安全备份”导出或恢复；仍建议另行导出到电脑。
- Windows 无法运行原生 UI；相机、缩放裁剪、字号放大、中文 PDF 排版（单段超页会拒绝生成，需缩短文字或使用题图）、双面打印和 iOS 15.5 真机须用户试用验收。编译通过不代表这些已完成验收。

## 编译

GitHub 开发分支 `feat/native-mvp` 的 Actions 先执行 `swift test`，再生成工程并构建未签名 IPA。下载 `Pickt-unsigned-ipa` 附件解压，获得 IPA、SHA256 和提交记录。IPA 需要自行重签侧载，不能直接无签名安装。

首个已核验构建：[9fdccf3 / 版本 0.1](https://github.com/wenna/pickt/actions/runs/39786707407)。点击页面下方 Artifacts 的 `Pickt-unsigned-ipa` 下载 ZIP 并解压，再将 IPA 导入侧载工具重签。普通库首开为空，可先用手动文字题体验组卷闭环。

## 2026-11-11 原生整页分题（0.2.0 / build 3）

代码接入真实 BigModel GLM-4.6V-Flash 单页请求；默认不上传，每次查看当前页后明确确认。家长设置提供密钥保存/移除，Keychain ThisDeviceOnly 保存，不进备份或日志；固定HTTPS地址和型号，拒绝重定向，不自动重试或切收费型号。2026-11-11 官方价目 https://docs.bigmodel.cn/cn/guide/start/pricing 仍列该型号输入输出免费，但政策可能改变。

收题：拍照/相册 → 当前页自动分题 → 右栏＋多选 → 单片段调整/补框/移除 → 合并与取消合并（支持跨页） → 逐题或统一分类 → 保存全部。图上仅显示边框，操作按钮独立在右栏；文字和公式保留原图，模型文字可修改。参考答案不由该接口自动生成。无密钥、失败或取消时保留当前选择，可用补框或「手动逐题收录/遮盖笔迹」。

候选坐标按0至1000转换并校验，拒绝坏格式、越界、过小框、空结果和截断返回；这只能防止格式错误，不能证明题框完整。批量题目和来源一次事务入库，失败不部分写入；图片可能留下未引用文件，原资料不受影响。未保存的收题会话仅在当前页面内保留，退出需重新选题。数据格式未改变，无需清库。

验证状态：Windows 无Swift/Xcode，新增4项解析/跨页合并/取消合并检查，原生测试及构建待macOS CI。没有提供个人密钥，尚未执行真实服务请求，账号可用性、公式文字准确率、切题完整性与真机触控仍待验收；不能称为达到试卷宝准确率。答案照片、整卷自动判题、自动去笔迹本轮尚未实现。

### 智谱密钥准备与使用

1. 用家长账号打开 https://open.bigmodel.cn/ ，注册并完成平台要求的账户步骤。
2. 在控制台创建 API Key，核对模型 GLM-4.6V-Flash 当前仍免费。不要选择 FlashX 或购买套餐来替代；如果账户要求付费才能使用，请暂停并反馈。
3. 侧载0.2.0后，在「家长设置 → 智谱免费视觉模型」输入密钥并保存。请勿把密钥发到聊天、GitHub或截图中。
4. 先用虚构或遮掉姓名学校的试卷，在拍试卷中确认上传一页；检查题干、选项、几何图及子题是否完整，调整后再保存。失败信息可反馈HTTP状态码，勿反馈密钥。
5. 密钥不跟随App备份迁移；需要时重新设置。移除后只影响后续云端调用，本地题库、打印、手动收题仍可用。
