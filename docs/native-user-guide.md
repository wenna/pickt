# 原生 App 首轮试用

这是按 Demo V2.4 实现的原生首轮版本。普通库首开为空，不含演示孩子资料。

1. 拍试卷：扫描或导入照片，单指框选，双指缩放与平移。每道题可以收录多个片段，手动遮盖笔迹；原图保留。下一步多选知识点、错因，补参考答案并保存。连续选下一题。
2. 练一练：筛选后手选题或按数量推荐，生成卷。顶部随时进入我的练习卷，不需要滚动到底部。
3. 打开练习卷可改名、创建不同留白排版、输出学生卷 / 家长页 / 全部。双面全部输出在需要时补白，家长页另起纸张。打印后仍待完成。
4. 纸上做完，打开对应卷，选择页脚排版版本，拍完成卷。逐题框选作答区使用系统 OCR；数值或单选答案只给比较建议，必须人工确认做对 / 再练 / 暂未做。每题点击保存后草稿持久保留，全部核对后才能入库。
5. 错题本可查最近结果、待核对和历史记录；错题和卷的管理入口支持按已确认规则整批软删除，在最近删除恢复。
6. 家长设置可导出完整图片备份包到文件 App，恢复前校验并在 App 内保存原资料安全备份。侧载刷新请覆盖安装，避免卸载丢数据。

## 首轮实现边界

- 真正的本地文字 OCR，不是模拟结果；年级默认六年级，科目默认数学，知识点依关键词给建议，均可修改。未做复杂公式语义理解或整卷自动对齐，拍完成卷需要逐题框选核对。
- 分类逐题保存；当前没有批量统一编辑分类、题序拖动、出卷模板和图库资产自动清理。新排版仅调整留白。没有接入大模型、云同步和付费服务。
- 备份为 `.picktbackup` 文件包，文件 App 的跨服务传输兼容性需设备验收。恢复前安全备份保留在 App 内，不自动清理；可从家长设置的“恢复前安全备份”导出或恢复；仍建议另行导出到电脑。
- Windows 无法运行原生 UI；相机、缩放裁剪、字号放大、中文 PDF 排版（单段超页会拒绝生成，需缩短文字或使用题图）、双面打印和 iOS 15.5 真机须用户试用验收。编译通过不代表这些已完成验收。

## 编译

GitHub 开发分支 `feat/native-mvp` 的 Actions 先执行 `swift test`，再生成工程并构建未签名 IPA。下载 `Pickt-unsigned-ipa` 附件解压，获得 IPA、SHA256 和提交记录。IPA 需要自行重签侧载，不能直接无签名安装。
