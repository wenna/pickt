# 原生整页分题实施计划

依据用户已确认 Demo 和 2026-11-11 的实施授权。沿用 SwiftUI/UIKit、iOS 15.5、本地数据格式；不增加付费或自建后端。

- 固定智谱 BigModel GLM-4.6V-Flash 适配，单页 JPEG、明确上传确认、Keychain、取消/超时/错误回退；模型坐标按约定0至1000转换并严格校验，拒绝截断或异常输出。
- 独立领域收题会话：候选、页号、多个片段、选择、合并及取消合并。题图真实裁切，识别文字可修改且不代替图像。服务未实测时不宣称准确率达标。
- 主收题界面显示原图与框，右栏加号不盖题干，选中后可调整/补框/移除；分类逐题编辑后一次事务保存，保留单页上传与离线手动入口。
- 先写解析/合并回归测试，再实现；macOS CI 测试和 iPhone 编译、IPA 核验；同步文档和每个完整逻辑改动的提交。

模型依据：2026-11-11 官方定价 https://docs.bigmodel.cn/cn/guide/start/pricing ，免费状态不是永久保证。官方调用示例 https://github.com/zai-org/GLM-V 。个人密钥不进入聊天或Git。真实接口及真机交互待用户配置后验收；答案照片和开放式自动判题另行实现。
